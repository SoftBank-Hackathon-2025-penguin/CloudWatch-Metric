## 🔢 2. 점수 계산 원리 (승규님 파트!)

### 입력 → 처리 → 출력

```
입력 (AWS 메트릭)
┌────────────────┐
│ 에러율: 2.5%   │
│ 응답속도: 450ms│
│ CPU: 65%       │
└────────┬───────┘
         │
         ↓
처리 (score.py)
┌────────────────────────────┐
│ 1. 각 메트릭 심각도 계산    │
│    에러율 2.5% → 0.5점      │
│    응답 450ms → 0.3점       │
│    CPU 65% → 0.5점         │
│                            │
│ 2. 가중치 적용             │
│    에러율 × 50%            │
│    응답 × 35%              │
│    CPU × 15%               │
│                            │
│ 3. 최종 점수 계산          │
│    = 45점                  │
└────────┬───────────────────┘
         │
         ↓
출력 (Frontend에 전달)
┌────────────────┐
│ 점수: 45점     │
│ 상태: ⚠️ 주의  │
│ 펭귄: 😟       │
│ 메시지:        │
│ "에러율이      │
│  높아지고      │
│  있어요!"      │
└────────────────┘
```

## ❓ 10. "이게 실제로 작동해?" 질문 답변

### 현재 상태:

```
┌──────────────────────────────────────┐
│ ✅ 로직: 완벽하게 작동               │
│    - 점수 계산: OK                  │
│    - 테스트: 50개 통과              │
│    - 에러 핸들링: OK                │
│                                      │
│ ❌ AWS 연결: 아직 안 함              │
│    - CloudWatch: 설정 전            │
│    - SNS: 연결 전                   │
│    - DynamoDB: 생성 전              │
└──────────────────────────────────────┘
```

### 실제 작동시키기 위해 필요한 것:

```
오늘 해야 할 일 (Day 2)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔴 1. CloudWatch Alarm 생성 (전준배님)
    - error_rate_alarm
    - latency_alarm
    - cpu_alarm

🔴 2. SNS Topic 연결
    - CloudWatch → SNS
    - SNS → Backend Webhook

🟡 3. Backend Java 이식
    - score.py 로직 → Java 코드
    - 승규님이 검토

🟡 4. DynamoDB 테이블 생성
    - deployments 테이블
    - alarms 테이블

🟢 5. 통합 테스트
    - 실제 Alarm 발생시켜보기
    - 점수 제대로 나오는지 확인
```
