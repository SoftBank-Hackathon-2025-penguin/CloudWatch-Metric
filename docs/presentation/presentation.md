## 2️⃣ 솔루션 (1분)

### Penguin-Land: 펭귄이 코치해주는 배포 경험

```
✨ 0~100점으로 단순화
✨ 펭귄이 상태를 알려줌
✨ 게임처럼 즐거운 경험
```

### 핵심 기능

**1. 실시간 건강 점수**
```
CloudWatch 메트릭 → ML 분석 → 0~100점
```

**2. 펭귄 코치**
```
점수에 따라:
  0~30점: 웃는 펭귄 + "🎉 완벽해요!"
  31~70점: 보통 펭귄 + "⚠️ 주의하세요"
  71~100점: 우는 펭귄 + "🚨 위험해요!"
```

**3. 게이미피케이션**
```
- 성공 시: 펭귄이 춤 + 컨페티 터짐
- 위험 시: 화면 흔들림 + 경고
- 연속 성공: 스트릭 카운터
```

## 4️⃣ 기술 스택 & 아키텍처 (1분)

### 시스템 구조

```
[CloudWatch] → [Anomaly Detection] → [SNS]
                       ↓
                 [점수 계산 엔진]
                       ↓
    [Backend API] → [Frontend] → [펭귄 애니메이션]
```

### 핵심 기술

**1. CloudWatch Anomaly Detection**
```
- ML 기반 자동 학습
- 평소와 "다른" 패턴 감지
- Fallback 임계값으로 안정성 확보
```

**2. 점수 계산 알고리즘**
```python
score = (에러율 × 50%) + (레이턴시 × 35%) + (CPU × 15%)

# Hybrid 방식
if ML_밴드_있음:
    severity = calculate_from_band()
else:
    severity = calculate_from_threshold()
```

**3. 기술 스택**
```
Frontend: Next.js + Lottie (펭귄 애니메이션)
Backend: Spring Boot + Python (점수 엔진)
Infra: Terraform + AWS CloudWatch
```

## 5️⃣ 차별화 포인트 (30초)

### 우리가 다른 이유

**1. ML + Fallback = 안정성**
```
Anomaly Detection: 지능적
Fallback 임계값: 안정적
→ 항상 작동 보장
```

**2. UX 중심 설계**
```
복잡한 대시보드 ❌
0~100점 + 펭귄 ✅
→ 초보자도 즉시 이해
```

**3. 재미 + 실용성**
```
펭귄 캐릭터: 즐거움
긴급 액션: 실용성
→ "꼭 써보고 싶다!"
```

### 예상 질문 & 답변

**Q1: "실제 ML 모델을 훈련시켰나요?"**
```
A: CloudWatch Anomaly Detection을 활용했습니다.
AWS에서 제공하는 ML 서비스로, 자동으로 학습합니다.
저희는 Fallback 시스템을 추가해 안정성을 높였습니다.
```

**Q2: "초기 데이터가 없으면 어떻게 하나요?"**
```
A: Fallback 임계값 시스템이 작동합니다.
AWS 모범 사례를 기반으로 설정한 임계값으로
항상 점수를 제공할 수 있습니다.
```

**Q3: "실제 프로덕션에서 사용 가능한가요?"**
```
A: 네! 실제 사용 가능하도록 설계했습니다.
점수 계산 로직, 메시지 생성, API 모두 실용적입니다.
해커톤 이후 오픈소스로 공개할 계획입니다.
```
