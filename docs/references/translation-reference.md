| 한국어 | 日本語 | 설명 |

---

## 🎯 프로젝트 개요 (Project Overview)

### 우리가 만든 것
- CloudWatch 메트릭을 **실시간으로** 분석하여 **건강 점수(0~100점)**를 계산
- 점수가 낮을수록 건강한 상태 (0점 = 완벽, 100점 = 위험)
- Slack으로 자동 알림 전송

### 日本語
- CloudWatchメトリクスを**リアルタイム**で分析し、**ヘルススコア（0〜100点）**を算出
- スコアが低いほど健康な状態（0点 = 完璧、100点 = 危険）
- Slackに自動通知を送信

| 점수 | 한국어 | 日本語 | 설명 |
|------|--------|--------|------|

## 🎨 고유 기능 (Unique Features)

### 1. Problem Metrics (문제 메트릭 식별)
- **한국어**: 어떤 지표가 문제인지 자동으로 찾아냄
- **日本語**: どのメトリクスが問題なのか自動的に特定

### 2. Severity (심각도)
- **한국어**: 각 메트릭의 위험도를 0.0~1.0으로 수치화
- **日本語**: 各メトリクスの危険度を0.0〜1.0で数値化

### 3. Penguin Animation (펭귄 애니메이션)
- **한국어**: 상태에 따라 펭귄 표정이 변화 (행복→걱정→우는표정)
- **日本語**: 状態に応じてペンギンの表情が変化（幸せ→心配→泣き顔）
